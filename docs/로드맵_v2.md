## 큰 그림 — 3트랙

```
[트랙 A] 시뮬                     [트랙 B] 진짜 운영
PWA + 시뮬 GAS + 시뮬 시트(29열)    사장님 운영 시스템 (50열, 1000건/년)
       ↓                                    ↓
       └────────────┬───────────────────────┘
                    ↓
        [트랙 C] Multi-Tenant SaaS
        Supabase + N 회사 + N 카테고리
```

- **트랙 A** = 사장님 진짜 운영에 영향 X. 자유 실험.
- **트랙 B** = 사장님 현재 본업. 함부로 손 안 댐.
- **트랙 C** = 미래. v2 비전의 종착지.

**중요**: A와 B를 통합해서 만들 게 아니라, **A는 학습용 / B는 그대로 유지 / C가 둘을 흡수**하는 구도.

## 결정 게이트 (사장님 답 대기)

### 결정 V1 — 트랙 A 마무리 vs 트랙 C 직진

`올잇_비전_v2.md` 의 결정 V1과 동일.

| 옵션 | 권장도 |
|---|---|
| A. 시뮬 GAS 결선 끝까지 → Supabase 마이그 | ⚠️ 시뮬 작업 일부 throwaway |
| B. **8-A 여기서 멈춤 → 트랙 C 직진** | ★ **추천** |
| C. 병행 | ⚠️ 자원 분산 |

→ B 추천 이유는 비전 v2 문서 참조. 사장님 답이 나오면 이 로드맵 갱신.

### 결정 V2 — 트랙 B 처리

`올잇_비전_v2.md` 의 결정 V2와 동일.

| 옵션 | 내용 |
|---|---|
| A. 운영도 Supabase로 마이그 (시뮬과 통합) | ★ 권장, 시점은 v3 검증 후 |
| B. 운영은 Sheets 그대로, Supabase는 신규 | 분리 운영 |
| C. 병행 | 점진 통합 |
