## 3. 컴포넌트 패턴

### 3-1. 카드 (TaskCard, Stat, ListCard)

```jsx
<div style={{
  background: t.bgElevated,
  border: `1px solid ${t.border}`,
  borderRadius: 12,            // 작은: 8-10, 큰: 14
  padding: "14px 16px",         // 작은: 10-12, 큰: 16-20
}}>
```

- shadow 거의 안 씀 — `bgElevated` + `border` 조합으로 깊이 표현
- hover/active: `.clickable` 클래스 (cursor pointer + active opacity 0.7 scale 0.98)

### 3-2. 버튼

| 종류 | 패턴 |
|---|---|
| **메인 (등록/제출)** | `padding: 16, borderRadius: 12, fontSize: 14, fontWeight: 700, background: canSubmit ? t.accent : t.bgInset, color: canSubmit ? "white" : t.textMuted` + 좌측 아이콘 |
| **보조** | `padding: "8px 12px", borderRadius: 8-10, fontSize: 11-12, fontWeight: 700, background: t.bgInset 또는 transparent` |
| **토글 (필터)** | `padding: "6px 12px", borderRadius: 8, fontSize: 11, fontWeight: 700`, 활성 = `t.accent` / 비활성 = `t.bgInset` |
| **수량 ± (32×32)** | `width/height: 32, padding: 0, borderRadius: 7, background: t.bgElevated, border: 1px t.border, fontSize: 16, fontWeight: 600` |
| **링크 텍스트** | `background: transparent, border: none, color: t.accent, fontSize: 11-12, fontWeight: 600` |
| **경고 액션 (warning bg)** | `background: t.warning, color: "#1A1512"` (다크 배경 위에 노란 버튼 — EngineerApp:1055) |

### 3-3. 입력 필드

```jsx
<input style={{
  width: "100%",
  padding: "12px 14px 12px 38px",        // 좌측 38px: 아이콘 자리
  background: t.bgElevated,
  color: t.text,
  border: `1.5px solid ${value ? t.accent : t.border}`,  // ★ value 있으면 accent
  borderRadius: 10,
  fontSize: 13,
  fontWeight: 600,
  boxSizing: "border-box",
  outline: "none",
}}/>
```

- 아이콘 prefix: `position: absolute, left: 14, top: "50%", transform: "translateY(-50%)", color: t.textMuted` (size 14)
- multiline은 `top: 14, transform: none` (위 정렬)

### 3-4. 배지 / 태그 / 상태 표시

| 종류 | 패턴 |
|---|---|
| **상태 배지 (pill)** | `fontSize: 10-11, fontWeight: 700-800, padding: "4px 9-10px", borderRadius: 100, background: ss.bg, color: ss.color` |
| **카운트 배지** | `fontSize: 9-10, fontWeight: 800, padding: "2px 6px", borderRadius: 4` |

## 7. 디자인 컨셉

### 7-1. 톤

- **다크 모드 우선** — 기사가 현장 / 야간 작업 잦음, 눈 부담 ↓
- **Warm dark** (`#1A1512` brown 톤) — 산업/작업 맥락. 차가운 검정보다 친근.
- **핑크 액센트** (`#FF1B8D`) — 강조 1곳에만. 카드 안에 한 군데.
- **둥근 카드** (12-14) — 부드러움, 모바일 친화.
- **큰 액션 버튼** (padding 16) — 손가락 터치 우선.
- **한국어 / 한국 운영** — 모든 status / enum / UI 한글. 영문 폰트는 숫자/코드만.

### 7-2. "튀지 않는 디자인" 원칙

| Do | Don't |
|---|---|
| 카드는 `bgElevated` + 옅은 border | 큰 그림자 / 그라디언트 / 화려한 배경 |
| accent 색은 카드 안 1곳만 | 여러 곳 뿌리기 |
| 숫자/코드는 mono | 한글에 mono 적용 |
| radius 12-14 | radius 24+ 너무 둥글게 |
| Spoqa 한글 / system-ui 메타 | Tailwind 클래스 (코드베이스 인라인 패턴) |
