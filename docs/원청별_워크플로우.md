## 4. 원청별 워크플로우

### 4-1. 올데이케어 (O)

| 항목 | 내용 |
|---|---|
| 접수 | 사장님 / 영업 / 카톡 / 전화 → **operator(관리자)가 PWA 입력** |
| 해피콜 | ❌ |
| 일정 협의 | ✓ 필요 (operator가 고객과 직접 통화 → PWA 일정 확정) |
| 배정 | 가스 = `auto_first_accept` / 그 외 = `manual_with_recommendation` |
| 결제 | 현장 결제 (현금/카드) 또는 회사 정산 — 자체 영업이라 마진 100% |
| 정산 | 사장님 = 단가 (정액 0) — `payments.principal_amount = 0`, 화면 노출 X |

### 4-2. 쿨가이 KA (아버지) / KB (아들)

| 항목 | 내용 |
|---|---|
| 접수 | partner (PWA 신규 접수) **또는** 카톡 → operator 입력 |
| 해피콜 | ❌ |
| 일정 협의 | ✓ 필요 (가스는 자동 배정이지만 일정은 고객과 협의 필요할 수도 — 즉시/예약 옵션) |
| 배정 | 가스 (`gas_charging`) = `auto_first_accept` / 세척·점검·설치 = `manual_with_recommendation` |
| 결제 | 카드/계좌 (쿨가이 회사 통해 → 사장님 → 기사) |
| 정산 | 매월 정산 — KA 10% / KB 35% (예상금액비율) |

**KA vs KB 차이**:
- 정산 비율만 다름 (KA = 사장님 마진 큰 / KB = 표준)
- 작업 종류 / 워크플로우 / 화면은 동일
- DB는 `principal_id` 별도 row (`commission_policies` 정책 row 분리)

### 4-3. 용인컴퍼니 (Y)

| 항목 | 내용 |
|---|---|
| 접수 | 외주 카톡 / 전화 → operator 입력 |
| 해피콜 | ❌ |
| 일정 협의 | ✓ 필요 |
| 배정 | 가스 = `auto_first_accept` / 그 외 = `manual_with_recommendation` |
| 결제 | 카드/계좌 (용인 회사 통해) |
| 정산 | 작업당 정액 1만 차감 (`금액` calc_method) |

### 4-4. 유솔홈케어 H (현금) / N (네이버)

| 항목 | H (현금) | N (네이버) |
|---|---|---|
| 접수 | **외부 시트 자동 동기화** (유솔이 시트 export → 사장님이 PWA에 import) | 동일 (단 결제 채널만 다름) |
| 해피콜 | ❌ | ❌ |
| 일정 협의 | 시트에 정보 다 들어옴 → operator는 일정 확인만 | 동일 |
| 배정 | 세척 = `manual_with_recommendation` / 옵션 = 동일 | 동일 |
| 결제 | 유솔이 현금 직수령 → 매주 사장님 송금 | **네이버페이** → 유솔(중간) → 사장님 → 기사 (작업일+15일+) |
| 정산 | `비율` 15% (단가 전체 base) | `수량비율` 15% (단가 - **`naver_fee` 차감** base) |
| Phase 1 | ✓ 작업 데이터 입력 + 정산 자동 | **작업 데이터만 입력**, 정산 = 수동 (`naver_fee` 직접 입력), 자동화 Phase 2 |

### 4-5. 세스코 (C) — Phase 1 제외

계약 종료. 시스템에 입력 X. Phase 2 잔여 작업이 있으면 수동 처리.

## 5. 새 접수 PWA 화면 가이드

### 5-1. 화면 위치

대표/관리자 메인 → **"새 접수"** 메뉴 (또는 BottomNav `+` 버튼)

### 5-2. 그룹 구조 (헤드 → 카드)

```
┌─────────────────────────────┐
│ 🏪 올데이케어 (자체)          │  ← 그룹 헤드 (원청 색상 라벨 + 카운트)
│  └ [+ 직접 입력]              │  ← 액션 버튼
├─────────────────────────────┤
│ 🏢 쿨가이 KA  (3건)          │
│  ├ 카드 1: 김XX / 강남 …      │
│  ├ 카드 2: ...                │
│  └ [+ 카톡 붙여넣기]          │
├─────────────────────────────┤
│ 🏢 쿨가이 KB  (1건)          │
│  └ ...                        │
├─────────────────────────────┤
│ 🏢 용인컴퍼니 (2건)           │
│  └ ...                        │
├─────────────────────────────┤
│ 📥 유솔 H (현금)  (5건)       │  ← 외부 시트 동기화 그룹
│  └ [📥 시트 import]            │
├─────────────────────────────┤
│ 📥 유솔 N (네이버) (8건)      │
│  └ [📥 시트 import]            │
│  └ ⚠ Phase 1: 정산 수동 입력   │  ← 알림 배지
└─────────────────────────────┘
```


### 5-4. 액션 버튼 — 원청별 다름

| 원청 | 주 액션 (`+ 신규 접수` 버튼 라벨) | 흐름 |
|---|---|---|
| 올데이케어 | **+ 직접 입력** | 빈 폼 → 고객/주소/작업 입력 → 저장 |
| KA / KB / 용인 | **+ 카톡 붙여넣기** (parseKakao v2 사용) | 텍스트 paste → auto-parse → 6 필드 자동 입력 → 저장 |
| 유솔 H / N | **📥 시트 import** | CSV / 직접 paste → 행별 매핑 → 일괄 INSERT |
| 유솔 N (특수) | **+ 시트 import + naver_fee 입력** | 시트 import 시 네이버 수수료도 직접 입력 |
