## 핵심 발견 (사장님 답변에서)

### 1. 정보 비대칭 패턴 — 운영 자산 ★

```
기사기준금  =  원청에게 알려진 기사 수익 (표면)
기사AD     =  실제 기사 받는 금액 (이면)
차이       =  사장님 자동 마진 (정보 비대칭)
```

DB는 두 값 모두 저장 (`engineer_base` + `engineer_actual_ad`). partner는 둘 다 안 봄. 기사도 자기 AD만. 사장님만 가시.

### 2. 카테고리별 분배 철학

| 작업 종류 | 누가 노력? | 분배 |
|---|---|---|
| 메인 작업 (에어컨 청소 등) | 사장님 영업/관리 | 사장님이 마진 확보 |
| 옵션 (송풍팬, 실외기 등) | 기사 현장 영업 | 기사 85% / 원청 15% / 사장님 0 |
| 출장비 (작업 불가 시) | 기사 출장만 | 기사 100% |
| 현장 추가금 (메인 외 추가) | 사장님 + 기사 | 50/50 (단 카테고리 예외) |

### 3. **수량은 모든 정책의 기본 차원** ★

모든 calc_method에서 수량 곱은 자동. 단가 한 대당 분배 → × `qty`.

예외: `비율_총액기준` 만 (단가×qty + 추가금) 합계 기준 → 수량 곱 X (이미 합계 사용).

출장비/현장추가금은 수량 무관 (한 번 발생).

### 4. 4 원청 (세스코 제외)

| 약자 | 회사명 | 구분 | 정책 |
|---|---|---|---|
| O | 올데이케어 | 직영 (자체 영업) | `금액` (정액 0) |
| KA | 쿨가이 (아버지) | 직영 | `차감후비율` (세척) + 가스 `예상금액비율` **10/50/40** / `비율_총액기준` |
| KB | 쿨가이 (아들) | 직영 | `차감후비율` (세척) + 가스 `예상금액비율` **35/50/15** / `비율_총액기준` |
| Y | 용인컴퍼니 | 직영 | `금액` (정액 1만) |
| H/N | 유솔홈케어 | 위탁 (현금/네이버 분리) | `비율` 15% (채널별 단가 다름) |
| ~~C~~ | ~~세스코~~ | ~~위탁~~ | **계약 종료, Phase 1 제외** |

## 8가지 계산방식 — 매핑

| calc_method | 사용처 | 핵심 |
|---|---|---|
| 차감후비율 | 쿨가이 에어컨 세척 | (단가 - 기사기준금) × rate = 원청, AD = 기사 (한 대당) |
| 비율 | 유솔 네이버 일반 | 단가 × rate = 원청, AD = 기사 (한 대당) |
| 금액 | 용인, 올데이케어 | 정액 = 원청, AD = 기사 (한 대당) |
| 수량비율 | 시트 호환 (= `비율` 동일 처리) | 모든 case가 수량 곱이라 별도 의미 X, enum 유지 |
| AG전체_AD반반 | 유솔 추가선택 (냉매점검 등) | 기본=원청100%, 추가=50/50, 출장=기사100% |
| 예상금액비율 | 쿨가이 가스 (KA: 10/50/40, KB: 35/50/15) | 견적 × `principal_fee%` (KA 10% / KB 35%) / 기사 50% / 나머지 사장님 — **정책 행 동적 분기** |
| **비율_총액기준** | **쿨가이 가스 1way/4way/원형 2개+** | **(단가×qty + 추가금) × 비율** — 25/50/25 |
| 추가선택 | 유솔 옵션 (송풍팬, 실외기) | 기사 85% / 원청 15% / 사장님 0 (한 대당) |

## Postgres 함수 — 단일 진입점

```sql
-- 정책 룩업 + 분배 결과 반환
-- 입력: 단가(한 대) + 수량 + 추가금 + 출장비
-- 출력: jsonb { engineer, principal, owner, is_balanced }
CREATE OR REPLACE FUNCTION compute_payment(
  p_tenant_id      uuid,
  p_principal_code text,        -- 'O','K','Y','H','N'
  p_service_code   text,        -- 'clean','install','recharge',...
  p_appliance_code text,        -- 'wall','stand',...
  p_qty            numeric,     -- 수량 (한 작업 안의 동일 work_type 대수/면적)
  p_unit_price     int,         -- 단가 (한 대당)
  p_extra_fee      int DEFAULT 0,  -- 현장 추가금 (수량 무관, 한 번)
  p_travel_fee     int DEFAULT 0   -- 출장비 (수량 무관, 한 번)
) RETURNS jsonb AS $$
DECLARE
  policy             commission_policies%ROWTYPE;
  rate               numeric;
  ad_rate            numeric;
  base               int;
  ad                 int;          -- 기사 실제 수령 (한 대당)
  fixed              int;          -- 정액 (한 대당)
  unit_engineer      int := 0;     -- 단가 한 대당 분배
  unit_principal     int := 0;
  unit_owner         int := 0;
  engineer           int := 0;     -- 최종 (수량 적용 + 추가금/출장비)
  principal          int := 0;
  owner              int := 0;
  total_base         int;
  extra_done         boolean := false;  -- 비율_총액기준은 추가금 이미 분배
  product_total      int;          -- 단가 × 수량
BEGIN
  -- 1. 정책 룩업
  SELECT * INTO policy FROM commission_policies
  WHERE tenant_id = p_tenant_id
    AND principal_code = p_principal_code
    AND service_code = p_service_code
    AND (appliance_code = p_appliance_code OR appliance_code IS NULL)
    AND CURRENT_DATE BETWEEN effective_from
                          AND COALESCE(effective_to, DATE '9999-12-31')
  ORDER BY appliance_code NULLS LAST
  LIMIT 1;

  IF NOT FOUND THEN
    RETURN jsonb_build_object('ok', false, 'error', '정책 없음 — 수동 입력 필요');
  END IF;

  base          := COALESCE(policy.engineer_base, 0);
  ad            := COALESCE(policy.engineer_actual_ad, base);
  product_total := (p_unit_price * p_qty)::int;

  -- 2. calc_method 별 단가 한 대당 분배 (비율_총액기준은 별도 처리)
  CASE policy.calc_method

    WHEN '차감후비율' THEN
      -- 쿨가이 세척: (단가-base)×rate = 원청, AD = 기사
      rate := (regexp_replace(policy.principal_fee, '[^0-9.]', '', 'g'))::numeric / 100;
      unit_engineer  := ad;
      unit_principal := round((p_unit_price - base) * rate);
      unit_owner     := p_unit_price - unit_engineer - unit_principal;

    WHEN '비율' THEN
      -- 유솔 네이버: 단가×rate = 원청, AD = 기사
      rate := (regexp_replace(policy.principal_fee, '[^0-9.]', '', 'g'))::numeric / 100;
      unit_engineer  := ad;
      unit_principal := round(p_unit_price * rate);
      unit_owner     := p_unit_price - unit_engineer - unit_principal;

    WHEN '수량비율' THEN
      -- 시트 호환 — '비율'과 동일 처리 (수량 곱은 아래 통합)
      rate := (regexp_replace(policy.principal_fee, '[^0-9.]', '', 'g'))::numeric / 100;
      unit_engineer  := ad;
      unit_principal := round(p_unit_price * rate);
      unit_owner     := p_unit_price - unit_engineer - unit_principal;

    WHEN '금액' THEN
      -- 용인/올데이케어: 정액 = 원청, AD = 기사
      fixed := COALESCE((regexp_replace(policy.principal_fee, '[^0-9]', '', 'g'))::int, 0);
      unit_engineer  := ad;
      unit_principal := fixed;
      unit_owner     := p_unit_price - unit_engineer - unit_principal;

    WHEN '추가선택' THEN
      -- 유솔 옵션: 기사 85% / 원청 15% / 사장님 0 (한 대당)
      unit_engineer  := round(p_unit_price * 0.85);
      unit_principal := round(p_unit_price * 0.15);
      unit_owner     := p_unit_price - unit_engineer - unit_principal;

    WHEN '예상금액비율' THEN
      -- KA(아버지) 10/50/40 vs KB(아들) 35/50/15 — principal_fee 동적 분기
      rate    := (regexp_replace(policy.principal_fee, '[^0-9.]', '', 'g'))::numeric / 100;
      ad_rate := COALESCE(policy.engineer_ad_rate, 0.5);
      unit_principal := round(p_unit_price * rate);                    -- KA 0.10 / KB 0.35
      unit_engineer  := round(p_unit_price * ad_rate);                 -- 보통 0.50
      unit_owner     := p_unit_price - unit_engineer - unit_principal; -- KA 0.40 / KB 0.15

    WHEN 'AG전체_AD반반' THEN
      -- 유솔 추가선택 냉매점검: 기본 = 원청 100%
      unit_engineer  := 0;
      unit_principal := p_unit_price;
      unit_owner     := 0;

    WHEN '비율_총액기준' THEN
      -- 쿨가이 가스 1way/4way/원형 2개+: (단가×qty + 추가금) × 비율
      -- 수량을 이미 반영한 합계 기준 → 아래 수량 곱 SKIP, 추가금도 SKIP
      rate    := (regexp_replace(policy.principal_fee, '[^0-9.]', '', 'g'))::numeric / 100;
      ad_rate := COALESCE(policy.engineer_ad_rate, 0.5);
      total_base := product_total + COALESCE(p_extra_fee, 0);
      principal := round(total_base * rate);
      engineer  := round(total_base * ad_rate);
      owner     := total_base - engineer - principal;
      extra_done := true;

    ELSE
      RETURN jsonb_build_object('ok', false, 'error', '미구현 calc_method: ' || policy.calc_method);
  END CASE;

  -- 3. 수량 곱 (비율_총액기준 제외 — 이미 위에서 합계 처리됨)
  IF policy.calc_method <> '비율_총액기준' THEN
    engineer  := unit_engineer  * p_qty;
    principal := unit_principal * p_qty;
    owner     := unit_owner     * p_qty;
  END IF;

  -- 4. 현장 추가금 (수량 무관, 한 번)
  --    기본 50/50. 비율_총액기준은 이미 처리됨 (skip).
  --    예상금액비율은 원청 0% (사용자 답변 Q6).
  IF p_extra_fee > 0 AND NOT extra_done THEN
    IF policy.calc_method = '예상금액비율' THEN
      engineer := engineer + round(p_extra_fee * 0.50);
      owner    := owner    + (p_extra_fee - round(p_extra_fee * 0.50));
      -- principal 변동 없음
    ELSE
      engineer := engineer + round(p_extra_fee * 0.50);
      owner    := owner    + (p_extra_fee - round(p_extra_fee * 0.50));
    END IF;
  END IF;

  -- 5. 출장비 (수량 무관, 작업 불가 시): 기사 100%
  IF p_travel_fee > 0 THEN
    engineer := engineer + p_travel_fee;
  END IF;

  -- 6. 검증 + 반환
  RETURN jsonb_build_object(
    'ok',          true,
    'policy_key',  policy.policy_key,
    'calc_method', policy.calc_method,
    'engineer',    engineer,
    'principal',   principal,
    'owner',       owner,
    'total',       engineer + principal + owner,
    'input_total', product_total + COALESCE(p_extra_fee,0) + COALESCE(p_travel_fee,0),
    'is_balanced', (engineer + principal + owner)
                   = (product_total + COALESCE(p_extra_fee,0) + COALESCE(p_travel_fee,0))
  );
END;
$$ LANGUAGE plpgsql STABLE;
```

## DB 스키마 (그릇_아키텍처.md와 동기)

```sql
CREATE TABLE commission_policies (
  id                  uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id           uuid NOT NULL REFERENCES tenants(id),
  category_id         uuid NOT NULL REFERENCES categories(id),

  -- 룩업
  principal_code      text NOT NULL,
  service_code        text NOT NULL,
  appliance_code      text,
  qty_condition       text,                      -- '1대','2대이상','전체'

  -- 정책 파라미터
  unit_price_ref      int,
  engineer_base       int,
  engineer_actual_ad  int,                       -- ★ 정보 비대칭 핵심
  engineer_ad_rate    numeric,
  policy_type         text,
  principal_fee       text,

  -- 계산 (8 enum)
  calc_method text NOT NULL CHECK (calc_method IN
    ('비율','차감후비율','금액','수량비율','AG전체_AD반반',
     '예상금액비율','비율_총액기준','추가선택')),
  policy_key text NOT NULL,
  formula    text,

  effective_from date DEFAULT CURRENT_DATE,
  effective_to   date,
  notes          text,

  UNIQUE (tenant_id, policy_key, effective_from)
);

CREATE INDEX commission_policies_lookup
  ON commission_policies (tenant_id, principal_code, service_code, appliance_code);
```
