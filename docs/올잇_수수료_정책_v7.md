## 11개 calc_method

### 1. 직영_0 (올데이 세척)
- engineer = engineer_base (40K~100K, 기종별)
- principal = 0
- owner = product_price - engineer

### 2. 직영_50_50 (올데이 냉매)
- engineer = product_price × 0.5
- principal = 0
- owner = product_price × 0.5

### 3. 차감후비율_50 (KA/KB 세척)
- 가짜단가 사용 (engineer_base ~ 가짜단가 차이)
- engineer = (판매가 - 가짜단가) × 0.5
- principal = 0
- owner = 가짜단가 - engineer_base (회사 마진)

### 4. 비율_견적금액 (KA 냉매, 크리크린 세척/냉매)
- engineer = product_price × engineer_ad_rate (KA: 35%, 크리크린: 20%)
- 첫대/추가/2번째부터 등 단가 분기 박혀있음 (engineer_base 기준)

### 5. 비율_총금액 (KB 냉매)
- total = product_price + extra_fee
- engineer = total × 0.5
- principal = total × 0.35
- owner = total × 0.15

### 6. 정액 (용인컴퍼니 세척/냉매, 유솔H 냉매)
- engineer = engineer_base (기종별)
- principal = 10,000
- owner = product_price - engineer - 10,000

### 7. 비율_판매가 (유솔H 세척)
- engineer = engineer_base (기종별)
- principal = product_price × 0.15
- owner = product_price - engineer - principal

### 8. usol_n_본작업 (유솔N 세척)
- engineer = engineer_base × 1.10 (10% 가산, 부가세)
- principal = (product_price - 네이버수수료) × 0.15
- 네이버수수료 별도 spec 필요

### 9. usol_n_추가선택 (유솔N 송풍팬분해/실외기/피톤치드)
- engineer = product_price × 0.85
- principal = 0
- owner = product_price × 0.15

### 10. usol_n_냉매점검 (유솔N 냉매)
- 기본 (10,000원): 유솔이 100% (네이버 1만원)
- 현장추가: 기사 50% + 회사 50%

### 11. 출장비_30K (전 원청 출장비)
- engineer = 30,000 (기사 100%)
- principal = 0
- owner = 0
