# 올잇 PWA — 디자인 토큰

**작성일**: 2026-04-30
**원칙**: **"튀지 않는 디자인"** — 새 컴포넌트는 기존 패턴 그대로 따라가기
**스타일 방식**: **Tailwind 미사용**. 인라인 `style` + `THEMES` 객체 (다크/라이트). React 19.

## 1. 색상 시스템 (`src/shared/themes.js`)

다크/라이트 두 모드. 색상 토큰은 `t.xxx`로 참조 (`const t = THEMES[mode]`).

> ⚠️ **참고**: 일부 페이지(`LoginScreen.jsx` 등)가 `THEMES` 객체를 자체 복붙해서 들고 있음. shared/themes.js로 통일은 추후 정리 거리. 새 컴포넌트는 `import { THEMES } from "../shared/themes.js"` 권장.

### 다크 모드 (기본 — 운영 환경 default)

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#1A1512` | 페이지 배경 (warm dark brown) |
| `bgElevated` | `#221C18` | **카드 배경** (= primary surface) |
| `bgInset` | `#13100E` | 입력 필드 배경, 대조 영역 |
| `border` | `rgba(255, 220, 200, 0.06)` | 카드 테두리 (옅음) |
| `borderStrong` | `rgba(255, 220, 200, 0.10)` | 강조 테두리 |
| `text` | `#FAF8F5` | 본문 텍스트 (off-white, warm) |
| `textSecondary` | `#C4B5A6` | 부 텍스트 |
| `textMuted` | `#8A7B6F` | 약한 텍스트 (라벨/메타) |
| `textDim` | `#5C5048` | 거의 안 보일 정도 |
| **`accent`** | `#FF1B8D` | **브랜드 핑크 — 강조 1곳에만** |

| `success` | `#34D399` (또는 `#10B981`) | 완료/OK |
| `successBg` | `rgba(52, 211, 153, 0.10)` | |

|---|---|

## 2. 폰트

```css
/* PWA 컴포넌트 <style> 블록 안에서 CDN import */
@import url('https://cdn.jsdelivr.net/gh/spoqa/spoqa-han-sans@.../SpoqaHanSansNeo.css');
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600;700&display=swap');
```

| 용도 | 폰트 | 클래스 / 인라인 |
|---|---|---|
| **한글 본문** | Spoqa Han Sans Neo | `fontFamily: "'Spoqa Han Sans Neo', sans-serif"` |
| **영문/숫자 모노** | JetBrains Mono | `className="mono"` (전화번호, 작업번호, 금액) |
| **헤더/메타 작은 글자** | system-ui | `fontFamily: "system-ui"` |

### 사이즈 체계 (인라인 px)

| 용도 | size | weight |
|---|---|---|
| 페이지 제목 (h1) | 18-22 | 800 |
| 섹션 제목 (h2) | 14-16 | 800 |
| 본문 | 12-13 | 500-600 |
| 라벨 / 메타 | 10-11 | 600-700 (uppercase + letterSpacing 0.5 자주) |
| 작은 배지 | 9-10 | 700-800 |
| 큰 숫자 (금액 등) | 18-32 | 800 (mono) |

## 3. 컴포넌트 스타일 패턴

### 카드 (TaskCard, Stat 등)

```jsx
<div style={{
  background: t.bgElevated,
  border: `1px solid ${t.border}`,
  borderRadius: 12,            // 작은 카드: 8-10, 큰 카드: 14
  padding: "14px 16px",         // 작은: 10-12, 큰: 16-20
}}>
```

- shadow 거의 안 씀 — border + bgElevated 조합으로 깊이 표현
- hover/active: `.clickable` 클래스 (cursor pointer + active opacity 0.7 scale 0.98)

### 버튼

| 종류 | 패턴 |
|---|---|
| **메인 (등록/제출)** | `padding: 16, borderRadius: 12, fontSize: 14, fontWeight: 700, background: canSubmit ? t.accent : t.bgInset, color: canSubmit ? "white" : t.textMuted` + 좌측 아이콘 |
| **보조** | `padding: "8px 12px", borderRadius: 8-10, fontSize: 11-12, fontWeight: 700, background: t.bgInset 또는 transparent, color: t.text` |
| **토글 (필터 등)** | `padding: "6px 12px", borderRadius: 8, fontSize: 11, fontWeight: 700` — 활성: `t.accent` / 비활성: `t.bgInset` |
| **수량 ± (32×32)** | `width/height: 32, padding: 0, borderRadius: 7, background: t.bgElevated, border: 1px t.border, fontSize: 16, fontWeight: 600` |
| **링크 텍스트** | `background: transparent, border: none, color: t.accent, fontSize: 11-12, fontWeight: 600` |

### 입력 필드

```jsx
<input style={{
  width: "100%",
  padding: "12px 14px 12px 38px",        // 좌측 38px: 아이콘 자리
  background: t.bgElevated,
  color: t.text,
  border: `1.5px solid ${value ? t.accent : t.border}`,  // ★ focus/value 시 accent
  borderRadius: 10,
  fontSize: 13,
  fontWeight: 600,
  boxSizing: "border-box",
  outline: "none",
}}/>
```

- 아이콘은 `position: absolute, left: 14, top: "50%", transform: "translateY(-50%)", color: t.textMuted` (size 14)
- multiline은 `top: 14, transform: none` (위 정렬)

### 배지 / 태그 / 상태 표시

| 종류 | 패턴 |
|---|---|
| **상태 배지** (rounded pill) | `fontSize: 10-11, fontWeight: 700-800, padding: "4px 9-10px", borderRadius: 5 또는 100, background: ss.bg, color: ss.color` (status별 색상 맵) |
| **카운트 배지** (작은 라벨) | `fontSize: 9-10, fontWeight: 800, padding: "2px 6px", borderRadius: 4` |
| **컬러 dot** (활성/비활성) | `width: 8, height: 8, borderRadius: "50%", background: c` |

### 상태별 색상 맵 (TaskCard 패턴)

```jsx
const statusStyle = {
  "완료":     { color: t.success,  bg: t.successBg },
  "진행중":   { color: t.warning,  bg: t.warningBg },
  "확정":     { color: t.text,     bg: t.bgInset },
  "약속대기": { color: t.accent,   bg: t.accentBg },
  "미배정":   { color: t.danger,   bg: t.dangerBg },
};
```

## 4. 레이아웃

### 모바일 우선 (PWA = 핸드폰 폼)

- 페이지 컨테이너 `maxWidth: 420, margin: "0 auto"` — PC에서도 핸드폰 너비
- 페이지 패딩 `padding: 20` (좌우 균등)
- 카드 사이 `gap: 8-12` (flex column)
- 페이지 하단 `paddingBottom: 80` (BottomNav 자리 확보)

### 헤더 (sticky)

```jsx
<div style={{
  position: "sticky", top: 0, zIndex: 200,
  background: "rgba(10,10,10,0.96)",
  backdropFilter: "blur(20px)",
  borderBottom: "1px solid rgba(255,255,255,0.08)",
  padding: "10px 12px",
}}>
```

작은 메타 정보 영역 (역할/배지/테마 토글). fontSize 10 system-ui letterSpacing 2.

### 하단 탭 (BottomNav)

```jsx
<div style={{
  position: "fixed", bottom: 0, left: "50%", transform: "translateX(-50%)",
  width: "100%", maxWidth: 420,
  background: t.bgElevated, borderTop: `1px solid ${t.border}`,
  display: "flex", padding: "8px 8px 12px",
  zIndex: 100,
}}>
```

탭 4개 가로 균등 분배. 가운데 + (신규) 버튼은 살짝 도드라지게 (36×36 round bg accent).

## 5. 애니메이션 / 인터랙션

각 페이지 컴포넌트가 `<style>` 블록 안에 같은 클래스 선언:

```css
@keyframes slideUp { 
  from { opacity: 0; transform: translateY(8px); } 
  to   { opacity: 1; transform: translateY(0); } 
}
.fade-in   { animation: slideUp 0.4s ease-out; }
.mono      { font-family: 'JetBrains Mono', monospace; }
.clickable { cursor: pointer; transition: all 0.15s; }
.clickable:active { opacity: 0.7; transform: scale(0.98); }
```

LoginScreen에는 `pulse` (1.5s 무한 반복) 추가.

**원칙**: 가벼운 fade-in + click 시 살짝 누르는 피드백. 회전/바운스/큰 애니메이션 X.

## 6. 추천기사 시각화 시안 작성 시 — 권장 패턴

> "튀지 않는 디자인" — 기존 TaskCard / Stat 패턴을 그대로 따라가는 게 정답.

### 추천 기사 카드 (예시)

```jsx
<div className="clickable" style={{
  background: t.bgElevated,
  border: `1px solid ${t.border}`,
  borderRadius: 12,
  padding: "14px 16px",
}}>
  {/* 1행: 코드 + 이름 + 거리 (mono) + 상태 배지 */}
  <div style={{ display: "flex", justifyContent: "space-between", alignItems: "flex-start" }}>
    <div>
      <div className="mono" style={{ fontSize: 10, color: t.textMuted, fontWeight: 600 }}>E010-G</div>
      <div style={{ fontSize: 14, fontWeight: 800 }}>김태승 <span style={{ fontSize: 11, color: t.textMuted, fontWeight: 500 }}>· 마포구</span></div>
    </div>
    <span style={{
      fontSize: 10, fontWeight: 700, padding: "4px 9px",
      background: t.accentBg, color: t.accent, borderRadius: 100,
    }}>추천 1순위</span>
  </div>

  {/* 2행: 메타 (거리/소요/평점) — mono */}
  <div style={{ display: "flex", gap: 12, marginTop: 8, paddingTop: 8, borderTop: `1px solid ${t.border}` }}>
    <span className="mono" style={{ fontSize: 11, color: t.textSecondary, fontWeight: 600 }}>3.2km</span>
    <span className="mono" style={{ fontSize: 11, color: t.textSecondary, fontWeight: 600 }}>12분</span>
    <span style={{ fontSize: 11, color: t.success, fontWeight: 700 }}>⭐ 4.8</span>
  </div>
</div>
```

### Do

- ✅ 카드 = `bgElevated` + `border 1px t.border` + `borderRadius 12`
- ✅ 강조 색상은 **accent 한 곳만** (1순위 배지 등). 나머지는 textMuted/Secondary
- ✅ 숫자 / 코드 / 거리 / 시간 = `className="mono"`
- ✅ 한글은 fontFamily 상속 (Spoqa)
- ✅ `<ChevronRight size={14} style={{ color: t.textMuted }}/>` 우측 끝 — 상세 가능 카드 시그널
- ✅ 카드끼리 `gap: 8` (flex column)

### Don't

- ❌ 큰 그림자, 그라디언트, 배경색 강한 카드 (튐)
- ❌ accent 색을 여러 군데 뿌리기 (강조 의미 사라짐)
- ❌ Tailwind 클래스 ("bg-pink-500" 등) — 이 코드베이스는 인라인 + 토큰
- ❌ 한글에 mono 폰트 적용 (한글에 어울림 X)
- ❌ borderRadius를 24+ 등 너무 둥글게 (이 디자인 톤 X — 12-14 standard)
