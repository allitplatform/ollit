## Phase 2 — 안정화

**기간**: 2-3개월 (MVP 출시 후)
**목표**: 시범 운영 데이터로 다듬기, 운영 시스템 통합 검토

**할 일**:
- 버그 잡기 (시범 운영 중 발견된 것)
- UX 다듬기 (사장님/기사 피드백)
- 미뤘던 결정 답변 (fullAddress / region / remarks / settlementStatus 등)
- **유솔 네이버 자동화** — 시트 import + `compute_payment` 'N' 분기 (`유솔_네이버_상세.md` 참조)
- **가스 작업 선착순 자동 배정** — `tasks.assignment_type` enum + `engineer_assignments` 테이블 + 기사 PWA 수락 버튼 (Uber/카카오택시 콜 방식)
- **운영 시트(50열) 데이터 마이그레이션 검토** (시기는 신중히)
- 외부 시트 동기화(유솔) → Supabase Edge Function으로 이전 가능성
- 백업 정책 (Supabase 자동 백업 외 추가)
- 성능 측정 (1000건/년 → 만건/년 시 RLS 비용)

**시작 조건**: Phase 1 출시 + 1주 운영
**완료 기준**: 시범 사용자 피드백 라운드 완료, 큰 버그 없음
