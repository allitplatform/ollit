# 발행 주제 계획 v2 — 충남 시군 키워드 기준

블로그: 오케이홈케어 · 카테고리 "산소관리_벌초"
1일 2편 = 벌초 1편 + 에어컨 1편

**변경 이유:** 서비스 지역이 충청남도 전 지역으로 확정되면서 전국 단위 키워드는 버렸습니다.
`벌초대행` 같은 키워드는 산림조합·농협·대형 업체가 잡고 있어 신규 진입이 불가능합니다.
시군 키워드는 검색량이 작은 대신 **경쟁이 거의 없고, 검색하는 사람이 곧 고객**입니다.

---

## 키워드 구조

```
[시군명] + [벌초대행 / 벌초비용 / 산소관리 / 잡목제거]
```

15개 시군 × 4개 축 = 60개 조합. 이 중 인구·묘역 밀도 기준 상위부터 씁니다.

| 순위 | 시군 | 이유 |
|---|---|---|
| 1 | 천안 | 인구 최다, 수도권 거주 자녀 많음 |
| 2 | 아산 | 천안 인접, 신도시 유입 |
| 3 | 공주 | 전통 묘역 밀집 |
| 4 | 논산 | 문중묘 다수 |

| 8 | 예산 | 농촌 묘역 |
| 9 | 보령 | 남부 거점 |
| 10~15 | 계룡 · 태안 · 서천 · 청양 · 부여 · 금산 | 시즌 후 보강 |

**시군 글 비중: 19편 중 7편(37%).** 나머지는 정보성 글로 채워 광고성 판정을 피합니다.

### 시군 글 작성 규칙

1. 제목에 시군명 1회, 본문 소제목에 1회, 본문 중 2~3회 — 그 이상은 키워드 스터핑
2. 그 지역 고유 정보를 반드시 하나 넣기 (지역 산림조합 연락처, 대표 묘역 지형 특성, 접근로 등)
3. 나머지 80%는 시군과 무관한 정보성 내용 — 복사 글로 보이면 안 됩니다
4. **같은 틀로 15개 시군을 찍어내지 말 것.** 네이버가 유사 문서로 묶습니다
