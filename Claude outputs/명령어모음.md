# PowerShell 명령어 모음

프로젝트 폴더

```powershell
cd C:\Users\butto\Downloads\blog-automation\blog-automation
```

새 창을 열 때마다 이 줄을 먼저 실행하세요.

---

## 1. 로그인 (세션 만료 시에만)

```powershell
npm run login
```

브라우저에서 직접 로그인 → 터미널로 돌아와 Enter

---

## 2. 원고 검사 (발행 전 확인)

```powershell
node src/render.js post-02
```

글자수, 이미지 개수를 보여줍니다. 2,000~2,500자면 정상입니다.

---

## 3. 임시저장 (안전, 발행 안 됨)

```powershell
node src/publish.js post-02
```

---

## 4. 발행 창까지 (카테고리·태그 자동, 발행 버튼은 직접)

```powershell
node src/publish.js post-02 --live
```

---

## 5. 발행까지 자동

```powershell
node src/publish.js post-02 --live --confirm
```

---

## 배치 파일로 하실 경우

```powershell
.\1_로그인.bat
.\2_임시저장.bat post-02
.\3_발행창.bat post-02
.\4_발행.bat post-02
```

인자를 안 주면 `post-01`이 기본입니다.

---

## 주의

**`npm run` 은 쓰지 마세요.** `--live` 같은 옵션을 npm이 가로챕니다.
`node src/publish.js` 로 직접 실행하거나 배치 파일을 쓰세요.
